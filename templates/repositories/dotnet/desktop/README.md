# .NET Desktop Repository Templates

These templates are technology baselines, not complete applications. Replace placeholders, select a supported target framework and review all publish settings before use.

- `winforms.csproj.template` — modern SDK-style WinForms project with explicit high-DPI baseline.
- `wpf.csproj.template` — modern SDK-style WPF project.

The shared .NET repository templates in the parent directory remain applicable.
