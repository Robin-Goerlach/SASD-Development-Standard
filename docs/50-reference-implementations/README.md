# Referenzimplementierungen

Dieses Verzeichnis dokumentiert, welche externen SASD-Repositories zur Validierung des Standards verwendet werden und welche Erkenntnisse daraus entstehen.

Der Quellcode der Referenzprojekte verbleibt in den jeweiligen Projekt-Repositories.

Für Version 1.0 sind drei Pilotkategorien vorgesehen:

1. kleines C#/.NET-Werkzeug,
2. mittlere gepflegte Desktopanwendung,
3. komplexere geschichtete C#/.NET-Anwendung.

Für jedes Pilotprojekt werden mindestens Standardversion, Profile, Qualitätsstufe, Ausgangszustand, Maßnahmen, Abweichungen und Lessons Learned dokumentiert.
