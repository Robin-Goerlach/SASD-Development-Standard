# Glossar

**Status:** Arbeitsdokument

| Begriff | Bedeutung |
|---|---|
| Normativ | Enthält verbindliche oder empfohlene Anforderungen des Standards. |
| Informativ | Erläutert, begründet oder zeigt Beispiele, ohne selbst verbindliche Anforderungen zu setzen. |
| Profil | Ergänzt den Kernstandard für eine Technologie, Plattform oder Projektart. |
| Qualitätsstufe | Definiert den angemessenen Umfang der Anforderungen: Minimum, Recommended oder Production. |
| Referenzimplementierung | Konkretes Projekt, das die praktische Anwendung des Standards zeigt. |
| Compliance | Nachvollziehbarer Grad der Übereinstimmung eines Projekts mit dem Standard. |
| Abweichung | Bewusste Nichterfüllung einer Anforderung mit dokumentierter Begründung. |
| ADR | Architecture Decision Record; dokumentierte Architekturentscheidung. |
| Source of Truth | Verbindliche Quelle, aus der abgeleitete Darstellungen oder Exporte erzeugt werden. |
