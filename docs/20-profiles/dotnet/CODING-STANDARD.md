# C# Coding Standard

## Zweck

Definiert C#-Konventionen, Lesbarkeit, XML-Kommentare, Analyzer und Sprachfeatures.

## Geplanter Aufbau

- Geltungsbereich und Abgrenzung
- normative Anforderungen
- Zuordnung zu Qualitätsstufen
- Beispiele und Anti-Patterns
- erforderliche Nachweise
- zulässige Abweichungen
- verwandte Vorlagen, Checklisten und Tooling
