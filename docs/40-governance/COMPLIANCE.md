# Compliance-Modell

**Status:** Entwurf

## Grundidee

Compliance ist kein bloßes Ja/Nein-Merkmal. Ein Projekt dokumentiert:

- angewendete Standardversion,
- angewendete Profile,
- gewählte Qualitätsstufe,
- erfüllte Anforderungen,
- offene Maßnahmen,
- genehmigte Abweichungen.

Eine Vorlage für Projekt-Compliance wird im Rahmen von Version 1.0 erstellt.
