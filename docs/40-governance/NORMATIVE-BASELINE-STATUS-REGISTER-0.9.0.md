# Normative Baseline Status Register 0.9.0

## 1. Zweck

Dieses Register dokumentiert den aktuellen Lifecycle-Status der normativen Baseline 0.9.0,
ohne den bereits freigegebenen Dokumentkatalog 0.8.0 rückwirkend zu verändern.

Der Dokumentkatalog bleibt das historische, durch das Foundation- und Governance-Manifest
identifizierte Inventar 0.8.0. Für den aktuellen Status eines konkreten Dokuments sind dessen
Front Matter, dieses Register und der Approval Record 0.9.0 maßgeblich.

## 3. Abgrenzung

Das Register erklärt weder einen Release Candidate noch eine stabile Veröffentlichung. Die im
Approval Record dokumentierten Release-Auflagen bleiben offen, bis sie durch separate Nachweise
geschlossen wurden.
