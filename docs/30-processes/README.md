## Grundsatz

Die Prozesse schreiben Ergebnisse, Nachweise und Entscheidungspunkte vor, aber kein starres Wasserfallmodell. Schritte dürfen iterativ, überlappend oder mehrfach durchlaufen werden, solange Risiken, Entscheidungen und Freigaben nachvollziehbar bleiben.
