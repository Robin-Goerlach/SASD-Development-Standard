# Standard Release Governance Checklist

- [ ] Release version and type are defined.
- [ ] All normative documents in scope are Approved.
- [ ] Approval records reference the release commit.
- [ ] No required normative dependency is Draft or Planned.
- [ ] All repository validators pass in a clean checkout.
- [ ] Changelog and release notes are complete.
- [ ] Document manifest is complete.
- [ ] Open exceptions and known issues are visible.
- [ ] Git tag is annotated and points to the approved commit.
- [ ] Publication artefacts were generated from the approved commit.
- [ ] SHA-256 checksums are recorded.
- [ ] Standard Release Record is complete.
- [ ] Release decision is documented.
