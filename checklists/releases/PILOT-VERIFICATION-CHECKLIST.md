# Pilot Wave Verification Checklist

- [ ] Full target commit ID recorded.
- [ ] Environment and SDK/tool versions recorded.
- [ ] Restore completed successfully.
- [ ] Release build completed successfully.
- [ ] Automated tests completed successfully.
- [ ] Runtime smoke tests completed in the intended environment.
- [ ] Fresh and existing-data scenarios checked where applicable.
- [ ] Backup and rollback path checked.
- [ ] CI run references the same commit and passed.
- [ ] Security/package audit reviewed.
- [ ] Open findings classified.
- [ ] Gap Register and Evidence Map updated.
- [ ] Verification record committed.
- [ ] Follow-up wave remains blocked if blocker or major evidence is missing.
