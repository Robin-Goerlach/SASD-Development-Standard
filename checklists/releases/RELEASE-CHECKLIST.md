# Release Checklist

- [ ] Release scope and version are approved.
- [ ] Build and tests succeed from a clean environment.
- [ ] Documentation and installation steps are current.
- [ ] Changelog and release notes are complete.
- [ ] Dependencies and licenses were reviewed.
- [ ] Security checks were completed.
- [ ] Upgrade, migration, and rollback needs are documented.
- [ ] Release artefacts are reproducible and identifiable.
- [ ] Git tag and GitHub release use the approved version.
