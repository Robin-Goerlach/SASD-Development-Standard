# Normative Baseline Approval Review Checklist

## Scope

- [ ] The approval bundle is uniquely named.
- [ ] All included normative documents are listed.
- [ ] No unrelated document is included accidentally.
- [ ] Approved external dependencies are identified.

## Content review

- [ ] Purpose and scope are clear for every document.
- [ ] Normative requirements use stable IDs.
- [ ] Quality-level scaling is proportional.
- [ ] Evidence and exception handling are defined.
- [ ] Cross-layer responsibilities do not conflict.
- [ ] Solo-developer application remains practical.

## Technical review

- [ ] Metadata validation passes.
- [ ] Markdown-link validation passes.
- [ ] Requirement validators pass.
- [ ] Cross-bundle duplicate detection passes.
- [ ] Dependency-cycle detection passes.
- [ ] Generated indexes and manifests are current.
- [ ] Repository boundary and hygiene checks pass.

## Approval decision

- [ ] Pilot and CI conditions are explicitly evaluated.
- [ ] Maintainer approval is explicit and dated.
- [ ] Approval Record is complete.
- [ ] Approval Manifest was generated after the status change.
- [ ] Approval is not confused with release publication.
