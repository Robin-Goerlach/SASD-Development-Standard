# Desktop UX Review Checklist

## Core workflow

- [ ] Current context and selected item are visible.
- [ ] Loading, empty, ready, changed and error states are distinguishable.
- [ ] Primary actions are clearly named and consistently positioned.
- [ ] Destructive actions are explicit and safely confirmed or undoable.

## Keyboard and focus

- [ ] Core workflows can be completed using the keyboard.
- [ ] Tab order follows the visible reading order.
- [ ] Focus is visible.
- [ ] Focus after navigation, validation and dialog closing is predictable.
- [ ] Shortcuts do not conflict with standard Windows conventions.

## Validation and errors

- [ ] Invalid fields remain identifiable after a dialog disappears.
- [ ] Error text explains impact and next action.
- [ ] Technical details are separated from the user message.
- [ ] Sensitive data is not exposed.

## Accessibility and display

- [ ] Non-obvious controls have accessible names.
- [ ] Information is not color-only.
- [ ] Contrast and disabled states remain understandable.
- [ ] Core windows work at supported DPI values.
- [ ] Minimum window size remains usable.
- [ ] Multi-monitor window restoration remains visible.

## Data views and settings

- [ ] Tables expose selection, sorting and editing state clearly.
- [ ] Large lists use appropriate filtering, paging or virtualization.
- [ ] Culture-sensitive formats are correct.
- [ ] Settings explain scope, default and restart impact.
