# Pilot Closeout Checklist

- [ ] mindestens eine Welle technisch im Ziel-Repository ausgeführt
- [ ] Ziel-Commit oder Tag festgehalten
- [ ] Build-, Test- und Laufzeitnachweise vorhanden
- [ ] Pilotziele bewertet
- [ ] offene Gaps und Ausnahmen gekennzeichnet
- [ ] Retrospektive abgeschlossen
- [ ] Standardänderungsvorschläge erfasst
- [ ] Portfolio-Status aktualisiert
- [ ] Referenzdokumente verlinkt
- [ ] keine formale Compliance über Proposed-Dokumente behauptet
