# Pilot Wave Review Checklist

- [ ] Eingangsbedingungen und Baseline nachgewiesen
- [ ] alle Arbeitspakete mit Evidenzen verknüpft
- [ ] Build und Tests nach der Welle erfolgreich
- [ ] Datenmigration und Rückfall geprüft
- [ ] Blocker und Major-Befunde geschlossen oder bewusst offen
- [ ] keine unnötige Architekturvergrößerung
- [ ] Dokumentation entspricht tatsächlichem Stand
- [ ] Gap Register aktualisiert
- [ ] Abweichungen und Ausnahmen dokumentiert
- [ ] Feedback an den Standard formuliert
- [ ] nächste Welle oder Pilotabschluss entschieden
