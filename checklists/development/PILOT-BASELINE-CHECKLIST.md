# Pilot Baseline Checklist

- [ ] Branch, Commit und Beobachtungsdatum erfasst
- [ ] Evidenzklassen verwendet
- [ ] Restore, Build, Test und Start getrennt bewertet
- [ ] öffentlich beobachtet und lokal verifiziert getrennt
- [ ] Daten, Secrets und Backups geschützt
- [ ] Stärken ebenso dokumentiert wie Lücken
- [ ] Blocker vor kosmetischen Änderungen priorisiert
- [ ] Unbekannte Punkte mit Klärungsmaßnahme erfasst
- [ ] Projektgröße, Qualitätsstufe und Profile getrennt bestimmt
- [ ] keine unberechtigte Compliance-Aussage erstellt
