# Pilot Implementation Review Checklist

- [ ] Target repository and baseline are identified.
- [ ] Artifact or commit has an immutable identity.
- [ ] Delivered files and scope are listed.
- [ ] Static checks are recorded with limitations.
- [ ] Build, test, runtime and CI claims are made only when executed.
- [ ] Data migration and rollback risks are explicit.
- [ ] Owner decisions such as licensing are not silently assumed.
- [ ] Overengineering and out-of-scope changes are checked.
- [ ] Gap Register uses `Artifact Prepared` rather than `Closed` when verification is missing.
- [ ] A verification plan exists before the next wave starts.
