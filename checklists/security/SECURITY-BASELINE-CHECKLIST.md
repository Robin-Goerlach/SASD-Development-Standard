# Security Baseline Checklist

- [ ] No credentials or private keys are stored in the repository.
- [ ] Inputs and external data are validated.
- [ ] Sensitive data handling is documented.
- [ ] Dependencies and their sources are known.
- [ ] Logging avoids secrets and unnecessary personal data.
- [ ] Backup and recovery needs are assessed.
- [ ] Security-relevant configuration has safe defaults.
- [ ] Known security limitations are documented.
