# Pilot Selection Checklist

- [ ] reales Projekt und Repository identifiziert
- [ ] Pilotkategorie festgelegt
- [ ] Wartungs- oder Nutzungsbedarf vorhanden
- [ ] Scope in kleinen Wellen bearbeitbar
- [ ] Qualitätsstufe und Profile vorläufig bestimmbar
- [ ] Risiken und sensible Daten berücksichtigt
- [ ] Quellcode bleibt im Ziel-Repository
- [ ] Referenzdokumentation kann nachvollziehbar gepflegt werden
- [ ] kein Pilot ausschließlich für kosmetische Strukturänderungen gewählt
- [ ] Erfolg und Stop-Kriterien definiert
