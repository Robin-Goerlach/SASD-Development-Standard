# Desktop Profile Adoption Checklist

## Classification

- [ ] Core quality level selected.
- [ ] C#/.NET Profile version recorded.
- [ ] Desktop Profile version recorded.
- [ ] WinForms, WPF or other technology decision documented.
- [ ] Supported Windows versions and architectures listed.
- [ ] Project size model selected: compact, maintained or complex.

## Users and workflows

- [ ] Primary user groups described.
- [ ] Core tasks and critical workflows prioritized.
- [ ] Online/offline expectations documented.
- [ ] Accessibility and localization needs considered.

## Architecture

- [ ] UI, application logic and infrastructure responsibilities identified.
- [ ] Navigation and dialog ownership defined.
- [ ] Background operations and cancellation model defined.
- [ ] Presentation logic test strategy selected.

## Data and lifecycle

- [ ] Program, configuration, user data, cache and log paths defined.
- [ ] Migration and backup needs assessed.
- [ ] Single- or multi-instance behavior decided.
- [ ] Startup, shutdown and crash recovery outlined.

## Distribution

- [ ] Publish model selected.
- [ ] Installation or portable distribution selected.
- [ ] Update and rollback needs assessed.
- [ ] Code signing need assessed.
- [ ] Release smoke-test environment defined.
