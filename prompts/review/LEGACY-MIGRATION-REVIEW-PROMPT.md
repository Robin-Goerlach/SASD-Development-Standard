# Prompt: Legacy-Projekt für SASD-Migration prüfen

Prüfe das beschriebene bestehende Projekt auf eine schrittweise Migration zum SASD Development Standard.

Priorisiere in dieser Reihenfolge:

1. Sicherung und reproduzierbarer Ist-Zustand,
2. Secrets, sensible Daten und kritische Sicherheitsrisiken,
3. Build, Start und Charakterisierungstests,
4. Dokumentation von Nutzern, Daten und Integrationen,
5. risikobasierte Standardabweichungen,
6. kleine reversible Migrationswellen,
7. erst danach strukturelle Modernisierung.

Vermeide die pauschale Empfehlung einer Neuentwicklung. Unterscheide:

- sofortige Stabilisierung,
- verpflichtende Lücken,
- sinnvolle Verbesserungen,
- bewusst aufgeschobene Maßnahmen,
- nicht anwendbare Anforderungen.

Liefere Assessment, Prioritäten, vorgeschlagene Wellen, Risiken, Rollbackideen und Abschlusskriterien.
