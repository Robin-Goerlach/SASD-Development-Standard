# Prompt: Pilot Baseline Assessment

Analysiere das bereitgestellte technische Projekt als Pilot für den SASD Development Standard.

Arbeite strikt evidenzbasiert und unterscheide:

- lokal verifiziert,
- öffentlich beobachtet,
- vom Projekt berichtet,
- abgeleitet,
- unbekannt.

Erstelle:

1. Projektklassifikation,
2. Stärken und vorhandene Nachweise,
3. Blocker, Major-, Minor- und Beobachtungsbefunde,
4. Risiken für Daten, Security, Build, Tests und Releases,
5. eine proportionale Bewertung ohne Overengineering,
6. priorisierte Migrationswellen,
7. offene Fragen und benötigte lokale Nachweise.

Behaupte keine erfolgreiche Builds, Tests oder Compliance, wenn dafür keine direkte Evidenz vorliegt.
