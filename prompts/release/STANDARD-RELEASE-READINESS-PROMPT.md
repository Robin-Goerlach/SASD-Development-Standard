# Standard Release Readiness Prompt

Assess a proposed SASD Development Standard release against its Version 1.0 acceptance criteria.

Require evidence for:

- Approved normative documents and approval records,
- immutable tag and commit identity,
- successful validators from a clean checkout,
- current generated indexes,
- pilot and compatibility evidence,
- known issues and exceptions,
- release notes and changelog,
- publication artefacts and checksums.

Return:

1. release decision: Ready / Conditionally Ready / Not Ready,
2. blockers,
3. major findings,
4. missing evidence,
5. exact remediation steps.

Do not treat prepared files, workflow definitions or source code as proof of successful execution.
