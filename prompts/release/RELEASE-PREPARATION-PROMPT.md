# Prompt: Release vorbereiten

Erstelle für das beschriebene Projekt einen Release-Readiness-Plan nach dem SASD Development Standard.

Berücksichtige:

- Version, Releaseart, Scope und Kompatibilität,
- Build aus sauberem Quellstand,
- automatisierte und manuelle Tests,
- Security-, Abhängigkeits- und Lizenzprüfung,
- Datenmigration, Backup und Rollback,
- Release Notes, Changelog und Nutzerhinweise,
- unveränderte Artefakte, Prüfsummen und Signierung,
- Freigaberollen,
- Nachprüfung nach Veröffentlichung,
- Hotfix- oder Abbruchverfahren.

Kennzeichne fehlende Nachweise als offen. Behaupte keinen erfolgreichen Test ohne bereitgestellte Evidenz.
