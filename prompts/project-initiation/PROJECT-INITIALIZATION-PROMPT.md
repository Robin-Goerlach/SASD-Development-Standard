# SASD Project Initialization Prompt

**Status:** Initial draft

Use the SASD Development Standard to initialize the project described below.

Determine and document:

1. problem and product vision,
2. intended users and stakeholders,
3. goals and measurable outcomes,
4. scope and explicit non-goals,
5. project type, size, risk, and expected lifetime,
6. applicable quality level and profiles,
7. required documents and repository structure,
8. initial architecture and major dependencies,
9. risks, security considerations, and unknowns,
10. a bounded first milestone with acceptance criteria.

Do not invent missing business facts. Mark assumptions explicitly. Prefer a pragmatic structure appropriate to the project size and avoid unnecessary architecture.
